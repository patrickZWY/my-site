01 Finance verification

TLA-Finance

A verification workbench for investigating suspicious outputs from an agentic finance system.

Formal models and trace-based analysis that connect a violated constraint back to the output and the state that produced it.

02 Smart contract security

Checking Smart Contracts for Price Manipulation

A practical way to find out whether someone can trick a contract by manipulating a market price.

Some contracts act on prices an attacker can influence. Even a short-lived change can push the contract into an unsafe action.

03 Self-evolving test suites

SPS-VeriSpec

A test suite that evolves into the program’s ground truth — an executable record of what the code actually does.

Each cycle mines new oracles from the program’s own structure and keeps only the ones that survive validation. The trusted suite accumulates; unproven candidates stay quarantined until a human promotes them.
